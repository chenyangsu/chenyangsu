## What I'm Doing

- **Testing AI agents** - building [clinical-agent-evals](https://github.com/chenyangsu/clinical-agent-evals), a benchmark that scores an agent by the state it leaves in a simulated EHR
- **Shipping small tools** - [citecheck](https://github.com/sunami-lab/citecheck) catches hallucinated references by checking every `.bib` entry against Semantic Scholar, OpenAlex, Crossref and arXiv (`pip install citecheck-refs`)
- **Contributing to open benchmarks** - hardening task validation and review tooling for [AI4S-Bench](https://github.com/AI4S-Bench/ai4s-benchmark)
- **Writing** - essays on AI agents and on building a research career, on [my blog](https://chenyangsu.github.io/blog/)
